# Data-analysis-project
An interactive COVID-19 Analysis Dashboard built entirely in Microsoft Excel using Pivot Tables, Pivot Charts, Slicers, Timeline Filters, and Excel formulas. The dashboard provides insights into total cases, deaths, recoveries, active cases, testing, vaccinations, and monthly trends through dynamic visualizations and interactive filtering.
# Project Objectives
•	Analyze global COVID-19 statistics. 
•	Compare total confirmed cases across countries. 
•	Monitor monthly trends in new COVID-19 cases. 
•	Analyze recoveries, deaths, active cases, testing, and vaccinations. 
•	Create an interactive dashboard with dynamic filters. 
•	Present data in a clear and user-friendly format.

# Key Insights
•	India recorded the highest total COVID-19 cases among the selected countries. 
•	Monthly new cases showed noticeable fluctuations during the reporting period. 
•	Recovery counts remained close to new case counts in several countries. 
•	Vaccination distribution was relatively balanced among the selected countries. 
•	Interactive filters allow users to explore trends by country, state, city, and reporting period.
